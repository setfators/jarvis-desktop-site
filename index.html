FAQ

Перед установкой

Нужна ли Ollama?

Нет. J.A.R.V.I.S поддерживает облачный ИИ. Ollama можно настроить дополнительно и использовать как локальную альтернативу для получения ответов.

Работает ли без интернета?

Локальные команды Windows и другие локальные функции могут работать без интернета. Для облачного ИИ, нейронной озвучки Edge TTS и некоторых функций распознавания речи требуется интернет-соединение. При настроенной Ollama можно использовать локальную модель.

На каких языках говорит JARVIS?

В приложении доступны русская, английская и латышская нейронные озвучки. Для их работы требуется интернет-соединение.

Где сохраняются настройки и история?

Настройки приложения и локальная память хранятся на компьютере пользователя, в отдельной папке данных JARVIS.

Как установить JARVIS?

Скачай установщик из раздела «Релизы», запусти его и следуй инструкциям. После установки JARVIS можно запускать через ярлык Windows.

Как обновить JARVIS?

Скачай новый установщик с этой страницы и запусти его. При обновлении пользовательские настройки и локальная память сохраняются в отдельной папке данных приложения.
